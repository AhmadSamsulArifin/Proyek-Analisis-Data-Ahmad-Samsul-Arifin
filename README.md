# Bike Sharing Data Analytics Dashboard 🚲

Aplikasi dashboard interaktif ini dibuat menggunakan Python dan framework Streamlit untuk memvisualisasikan faktor operasional yang memengaruhi tingkat penyewaan sepeda.

## Cara Menjalankan Dashboard di Lingkungan Lokal (Local)

### 1. Masuk ke Direktori Proyek
Buka terminal atau command prompt Anda, lalu arahkan ke folder tempat Anda menyimpan proyek ini:
```bash
cd Submission
```

### 2. Instalasi Library Dependency
Instal seluruh pustaka Python yang diperlukan dengan mengeksekusi perintah berikut:
```bash
pip install -r requirements.txt
```

### 3. Menjalankan Dashboard Streamlit
Jalankan berkas aplikasi utama dashboard dengan perintah:
```bash
streamlit run dashboard/dashboard.py
```
